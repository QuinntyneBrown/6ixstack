An alert describes a condition people should know about: a page-level failure ("We couldn't load events"), an event's status, or, with `banner`, a site-wide condition shown full width under the header (offline, back online, API unreachable, maintenance). Choose a `kind` (info, success, warning, danger), give a short `title`, put the explanation in the content, and add `actions` such as Try again. Use `role="alert"` only for failures that need attention now and `role="status"` for quiet updates.
