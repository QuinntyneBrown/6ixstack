# Developer events, Toronto and GTA, November 2026

Research compiled on November 1, 2026. Scope: in-person events in November 2026 from Mississauga through
Toronto to Oshawa, related to Christian-tech, .NET, AI, Angular, hackathons or product design. Every date
and venue below was read on the organizer's own page (Meetup, Luma, Eventbrite, gdg.community.dev, Devpost or
the organizer's site) on the research date unless the entry says otherwise. Addresses marked "on
registration" are hidden by the organizer until a registration is approved.

The **Import** column says whether the event is in the CLI import set (`sixstack events add --file`). An
event is importable only when it has a topic in the site's fixed set (`ai`, `dotnet`, `azure`, `angular`,
`react`, `aws`), a public street address, start and end times, and a known price or a page that shows it as
free. The 25 import files are generated by `make_events.py` in the research session's scratchpad and were
validated with `events add --dry-run` against a seeded SQLite database.

## CLI import

The 25 rows marked "Yes" are the import set. Each file sets `format` to `inPerson`, `timeZoneId` to
`America/Toronto`, one or more topics from the fixed set, and `isFree` or `priceCad`. All 25 passed
`sixstack events add --dry-run` against a seeded local SQLite database. The production write follows the
procedure in `infra/README.md` ("Managing production events"): open the SQL firewall for the operator's IP,
set `ConnectionStrings__Default`, set `SIXSTACK_ACTOR` to a moderator account, run `events add --file <f>
--yes` per file, verify with `events list --from 2026-11-01 --to 2026-11-30`, then close the firewall.
