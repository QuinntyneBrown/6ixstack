Navigation and page structure

How people move around 6ixstack: the site header and phone menu, back links, the settings section nav, the footer, and the page templates they frame.

Overview

6ixstack is shallow on purpose: four public sections (Events, Calendar, Communities, Speakers), detail pages one level below them, and a small signed-in area for organizers and moderators. Navigation is the site header on every page, a menu on phones, a back link on detail pages, a section nav inside settings, and the footer for everything else (About, Code of conduct, Contact, Calendar feeds, Organizer sign in). There are no breadcrumbs in the mocks because no route is deeper than two levels.

States

Nav links have default, hover, focus, active and current. The current link uses aria-current="page", which is also the styling hook, so the visual and the announced state cannot disagree.

EventsCalendarCommunities
EventsCalendarCommunities

Signed-in organizers see Your events and Notifications (with an unread count badge) in the header actions; the four public links never change.

Responsive

  • ≥ md (768px): nav links visible in the header; Submit event shows its label.
  • < md: links move into the menu panel; Submit event becomes icon-only with aria-label; the menu button appears.
  • Settings nav: horizontal scroll on phones and tablets; a sticky vertical column from lg (1024px).
  • Footer: links wrap onto as many rows as needed; the tagline sits above them on phones.
  • The sticky header height is matched by scroll-padding-top so focused elements and in-page targets are never hidden under it (2.4.11).

Accessibility

Landmarks (2.4.1)

Every page: skip link to #main first, <header> with <nav aria-label="Primary">, <main id="main">, <footer> with <nav aria-label="Footer">. The settings nav is aria-label="Settings sections", so three navs on one page are distinguishable.

Keyboard

KeyAction
TabSkip link → brand → nav links → Submit event → menu button (phones) → main content.
EnterFollows a link; opens the menu from the menu button.
EscCloses the menu and returns focus to the menu button.

Menu

The phone menu is a modal dialog: aria-modal="true", labelled by its title, focus moves to the first link, the page behind is inert, and closing returns focus to the menu button (mobile-nav).

Consistency (3.2.3)

The same four links, in the same order, with the same names, on every page.

Content

  • Section names are plural nouns, one word each: Events, Calendar, Communities, Speakers.
  • Back links name the destination, not the direction: “All events”, not “Back”.
  • The header action is a verb phrase: “Submit event”. The icon-only version keeps that text as its accessible name.
  • Footer links are the page names exactly as their h1s: “Code of conduct”, “Calendar feeds”, “Organizer sign in”.
