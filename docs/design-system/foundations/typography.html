Typography

Geist for everything, Geist Mono for times and codes, twelve role shorthands and a rem scale that respects the reader's font size.

Overview

6ixstack sets everything in Geist (with Inter and the system stack as fallbacks) and uses Geist Mono for times in the map, feed URLs and the large numerals on error pages. Type is set from twelve role shorthands (--text-*), each a full font value, so components never mix sizes, weights and line heights by hand.

  • Body text is 16px (--font-size-md); nothing a person must read is below 12px.
  • Headings use the tight line height and a slight negative letter spacing; page titles and the wordmark use --letter-spacing-tighter.
  • The hero headline and status codes are the only fluid sizes (--font-size-hero, a clamp() from 48 to 72px).

Usage

  • One <h1> per page (the page title); headings never skip a level.
  • Prose is capped at --layout-measure (65ch); paragraphs use text-wrap: pretty, headings text-wrap: balance.
  • Event times, prices and counts use tabular figures (.num) so columns of times line up in the agenda and table.
  • Overlines (“Featured this week”, day headings) are uppercase via CSS only; the source text stays sentence case for screen readers.
  • On phones the detail-page title drops from 36px to 30px (--font-size-3xl); no other size changes by breakpoint.
  • Don't set font-size in px or with viewport units outside --font-size-hero.

Accessibility

  • All sizes are rem, so 200% browser zoom and larger default font sizes scale text without clipping (1.4.4).
  • Layouts survive the 1.4.12 text-spacing overrides: line height 1.5×, paragraph spacing 2×, letter spacing 0.12em, word spacing 0.16em.
  • Minimum readable size is 12px (--font-size-xs) for captions and badges; 10px map labels are decorative and duplicated in the map's accessible list.
  • Muted and subtle text colours are checked at 4.5:1 on every surface they sit on; see contrast pairs.
