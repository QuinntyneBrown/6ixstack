Spacing

A 4px scale from 0 to 96px, one inside-versus-between rule, and three control heights.

WCAG 2.2 AASource: tokens/tokens.css

Overview

Spacing is a 4px scale named by multiples of four: --space-4 is 16px. Two half-steps (--space-1-5, --space-2-5) exist for compact controls such as the segmented filter and legend keys; everything else snaps to the 4px grid.

Inside and between

Inside a component the gap is at most --space-6; between components and sections it is at least --space-6. That one rule keeps a card's content visibly grouped and the page's sections visibly separate.

RelationshipToken6ixstack example
Icon to label--space-1–--space-2Map-pin icon and venue in an event row
Related controls--space-2–--space-3Topic chips in the filter bar; dialog footer buttons
Inside a card--space-4–--space-6Event card padding; form-card padding (32px from md)
Between list groups--space-8Day groups in the events list
Between page sections--space-12Event list and map column; hero and filter bar
Bands--space-14–--space-16The “Submit an event” CTA band; hero padding on desktop

Control heights and padding

Three control heights shared by buttons, inputs, selects and segmented items. Horizontal padding steps with height.

sm 32px / md 40px / lg 48px; padding 12 / 16 / 24px
SizeHeightHorizontal paddingUsed for
sm--space-3Row actions in the organizer table, map controls, chips
md--space-4Default buttons, inputs, selects, segmented filter
lg--space-6Sign-in, mobile nav “Submit an event”, sticky ticket CTA

Usage

  • Use gap on the layout primitives (.stack, .cluster, .grid) rather than margins on children.
  • Never write a spacing value in px or rem in component CSS; if the scale lacks a step, the design is off-grid.
  • Spacing does not change with viewport width; the layout tokens (--layout-gutter, --layout-margin) do.
  • Skeleton placeholders take widths in percentages of the line, not fixed rems.
