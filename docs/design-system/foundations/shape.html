Shape

Six radii that grow with element size and two border widths.

WCAG 2.2 AASource: tokens/tokens.css
  • Overview
  • Radius scale
  • Border widths
  • Usage

Overview

Corners grow with the size of the element: small marks are nearly square, controls are gently rounded, cards and dialogs more so, sheets the most. Pills and avatars are fully round.

Usage

  • Nested corners subtract the padding: a --radius-lg card with 8px padding holds --radius-md children.
  • Joined controls (input + addon, button group) round only their outer corners.
  • Don't mix radii within one component; a card with a --radius-full image looks like a different system.
