Foundation

Elevation

Four shadow levels, a surface hierarchy that works in both themes, and a nine-layer z-order.

WCAG 2.2 AASource: tokens/tokens.css
  • Overview

Overview

Elevation says what floats above what. 6ixstack uses four shadow levels, a dedicated map-tooltip shadow and a focus shadow, plus a nine-layer z-order. Shadows are tinted with --shadow-color, which is a cool ink in light theme and pure black in dark.

--shadow-focusTwo-ring focus for elements that cannot take an outline (map dots)

Surface hierarchy

Canvas < surface < raised. In light theme surface and raised are both white and the shadow does the separating; in dark theme the surfaces themselves get lighter as they rise, because shadows barely show on a dark canvas.

canvas
surface · shadow-1 (cards, event rows)
raised · shadow-4 (dialogs)
sunken (table header, code)
canvas
surface · shadow-1 (cards, event rows)
raised · shadow-4 (dialogs)
sunken (table header, code)

Z-order

A component never sets a raw z-index; it picks a layer.

LayerValueUsed for
--z-basePage content
--z-raisedHovered card, map focus ring
--z-stickySite header, map column, sticky ticket CTA
--z-dropdownMenus, sort select popups
--z-overlayDrawer and dialog backdrop
--z-modalDialogs, mobile nav
--z-popoverPopovers over dialogs
--z-toastToast region
--z-tooltipTooltips, skip link

Usage

  • Elevation follows interaction: a card rises from shadow-1 to shadow-2 on hover only when the whole card is a link target.
  • Only one thing sits at modal level at a time; stacked dialogs are not used in 6ixstack (the share dialog replaces the event menu rather than opening above it).
  • Dark theme shadows are stronger (0.4–0.6 alpha) and paired with lighter raised surfaces; never rely on a shadow alone to separate dark surfaces.
  • Sticky elements (site header, map column) use --z-sticky; toasts sit above dialogs so a “Link copied” toast stays visible while the share dialog is open.
