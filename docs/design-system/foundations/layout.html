Layout

Five breakpoints, a 4/8/12 column grid with token-driven gutters and margins, and the page templates 6ixstack is built from.

Overview

6ixstack is mobile first. Base styles target a 360px phone; breakpoints add columns, wider gutters and side-by-side regions such as the events list beside the map. Columns, gutter and margin are tokens that change at md and lg, so components read the token instead of writing their own media queries.

Breakpoints

TokenWidthColumnsGutterMarginWhat changes in 6ixstack
(base)0416px16pxSingle column; map above the list; menu button opens the mobile nav; dialogs are bottom sheets
--layout-breakpoint-sm416px16pxEvent rows get a date column; dialogs centre; toasts move bottom-right; two-column form grids
--layout-breakpoint-md824px32pxHeader nav links appear; calendar shows event titles in cells; stats row goes to four across
--layout-breakpoint-lg1232px48pxEvents list and sticky map side by side; settings nav becomes a sidebar; sticky ticket CTA hides
--layout-breakpoint-xl1232px48pxContent reaches the 1280px container and centres
--layout-breakpoint-2xl1232pxautoNothing grows; extra width becomes margin

Media queries use min-width in rem (48rem, 64rem). Custom properties cannot appear inside @media, so the values are repeated there by convention; this table is the reference.

Usage

  • Compose pages from .container, .page-grid, .stack, .cluster and .grid; see Layout primitives.
  • Card grids use repeat(auto-fill, minmax(18rem, 1fr)) so they reflow without breakpoints.
  • No page scrolls horizontally at 320px; only tables (inside .table-wrap) and the map scroll in two dimensions.
  • Use 100dvh, never 100vh, for full-height regions such as the desktop map.
