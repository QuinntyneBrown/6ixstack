Iconography

Outline icons on a 24-unit grid with 2px strokes and currentColor, one meaning per icon.

WCAG 2.2 AASource: tokens/tokens.css

Overview

6ixstack uses Lucide-style outline icons: a 24-unit grid, 2px round-capped strokes, no fills, and currentColor so an icon always matches its label. Icons are inline SVG with the .icon class; there is no icon font.

Usage

  • Decorative icons beside text get aria-hidden="true" and no title.
  • Icon-only buttons (menu, close, calendar previous/next, row edit) carry an aria-label with the verb and object, e.g. “Edit Fabric for Power BI developers”, and a tooltip.
  • Status icons in alerts and toasts use the status -icon colour; everywhere else icons inherit the text colour.
  • Leading icons go before the label with --space-2 between; external-link arrows trail.
  • Don't draw new icons at other stroke widths; take them from Lucide so the set stays consistent.

Accessibility

  • Meaningful icons (status, livestream) reach 3:1 against their background (1.4.11).
  • No icon is the only carrier of meaning (1.4.1): “Livestream available”, “Published” and error titles always accompany them.
  • Under forced-colors, currentColor strokes follow the system text colour automatically.
