Footer

The footer closes every page with the 6ixstack tagline and the links people need now and then: about, code of conduct, contact, feeds and organizer sign in.

Overview

The site footer closes every public page with the 6ixstack line ("Made in Toronto, for the people building in the 6ix.") and the links people need occasionally: About, Code of conduct, Contact, Calendar feeds and Organizer sign in.

  • Put secondary, site-wide destinations here; never the four primary ones from the site header.
  • Organizer sign in lives here deliberately: most visitors never need it, and it keeps the header to one action.
  • Status pages (404, 500, offline) keep the footer so people can still reach Contact.

Anatomy

  1. TaglineBody-sm, muted; one sentence.
  2. Footer navnav aria-label="Footer" list of muted links, underlined on hover.
  3. ContainerHairline top border, 40px top and 64px bottom padding, capped at the container width.

Responsive

  • Below 768px: tagline and links stack; links wrap with 8px row and 24px column gaps.
  • 768px and up: tagline left, links right on one row, wrapping only if needed.
  • The 64px bottom padding leaves room for the Events page's sticky CTA and the iOS home indicator; fixed bottom elements add env(safe-area-inset-bottom).

Theming

Reads --color-border-default (top edge), --color-fg-muted (text and links) and --color-fg-default (hovered link). It sits on the canvas, never on a different background.

Accessibility

Role and pattern

A <footer> (contentinfo landmark) at page level containing <nav aria-label="Footer"> with a list of links.

Keyboard

KeyAction
TabMoves through the footer links in order, last on the page.
EnterFollows a link.

Focus

Shared focus ring.

Labelling

The nav label "Footer" distinguishes it from the "Primary" nav. Links say where they go: "Calendar feeds", not "Feeds" or "Subscribe".

Contrast

Footer text on page
Hovered link on page
Focus ring on page

Motion

None.

Touch

Links are inline text with 24px horizontal and 8px vertical gaps; on phones each link is at least 24px tall.

Content

  • Sentence case link labels naming the page: "Code of conduct", "Organizer sign in".
  • One tagline, warm and local; no copyright boilerplate unless legal requires it.
  • Order: about the site, community rules, contact, tools (feeds), organizer access.
