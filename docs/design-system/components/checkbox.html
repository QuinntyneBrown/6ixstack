Checkbox

Checkboxes turn independent options on or off: the topics an event covers, the topics a feed includes, agreeing to the code of conduct.

WCAG 2.2 AAStatus: stableNative <input type="checkbox">

Overview

Use checkboxes when any number of options can be chosen, including none, and the choice takes effect when the form is submitted. Use a switch for a setting that applies immediately (email notifications), a radio group when exactly one option applies, and topic chips to filter a list in place.

Anatomy

  1. Box20px, --radius-xs, strong border; ink fill and white tick when checked.
  2. Label--text-body; the whole label is clickable.
  3. Description (optional)--text-body-sm, muted.

Sizes

One size: a 20px box in a row at least 24px tall.

States

Checkbox
Checked + disabled

Both themes

Responsive behaviour

  • Topic groups lay out in three columns from 640px and one column below.
  • Labels wrap under themselves, never under the box.

Theming

Reads --color-border-strong, --color-bg-surface, --color-accent (checked fill) and --color-fg-on-accent (tick). In dark the fill is off-white with an ink tick.

Accessibility

Role and pattern

Native checkbox inside its <label>; groups use <fieldset> + <legend>. A “select all” uses the native indeterminate property (APG Checkbox, mixed state).

Keyboard

KeyAction
TabMoves to each checkbox.
SpaceToggles.

Focus

The orange ring sits around the box; the label stays clear.

Labelling

The label is the name; the legend names the group (“Topics”). For a group error, the error is linked from every box with aria-describedby and focus goes to the first box.

Contrast

Box border
Checked fill on card

Motion

Fill transitions over --duration-fast.

Touch

The row is at least 24px tall and the label is part of the target.

Content

  • Labels describe the option positively: “Include streamed events”, not “Don't exclude streams”.
  • Group errors say what to do: “Pick at least one topic so people can find it.”
