Avatar

Avatars show a person by their initials; logo tiles show a community or a feed. Both sit beside a name and are decorative.

WCAG 2.2 AAStatus: stableInitials, image, icon

Overview

Use an avatar for a speaker, organizer or signed-in member; use a logo tile (rounded square) for a community, an organization or a feed. 6ixstack does not collect photos at launch, so initials are the default; the image variant is ready for speaker headshots.

Anatomy

  1. Circle--radius-full; people only.
  2. InitialsTwo letters, first and last name, label font scaled with the size.
  3. Logo tileRounded square (--radius-md, --radius-lg at large) for communities and feeds; initials or an icon.

States

Avatars are not interactive by themselves. When one is a control (the header account menu) it is wrapped in .avatar-btn, a real button, and takes the button focus ring.

Responsive

  • Sizes do not change with the viewport; pick the size for the context.
  • Below 640px, logo tiles inside .list__item hide so the title keeps its width.
  • Speaker profile headers keep the xl avatar above the name on phones and beside it from --layout-breakpoint-md.

Theming

Avatars use the accent-subtle pair (--color-accent-subtle / --color-fg-accent); logo tiles use --color-bg-subtle / --color-fg-default. In avatar groups each avatar has a 2px ring in --color-bg-surface so overlaps stay legible on cards in both themes.

Accessibility

Role and pattern

Decorative span with aria-hidden="true" whenever the name is next to it (always, in the mocks). When an image avatar stands alone, it is an <img alt="Priya Natarajan">. An avatar that opens a menu is a <button> following the menu button pattern.

Keyboard

KeyAction
—Decorative avatars are skipped.
Tab, Enter/SpaceOn .avatar-btn: focus and open the account menu.

Focus

Only .avatar-btn takes focus; the round shape gets the shared offset ring.

Labelling

Group overflow “+4” is decorative when the list of names follows; otherwise give the group role="img" aria-label="Priya Natarajan, Marcus Bell and 5 others".

Motion

None.

Touch

The account button is 40px; decorative avatars are not targets.

Content

  • Initials: first letter of the first and last name, uppercase (“PN”). One-word names use the first two letters.
  • Community tiles use the community’s own short form: “GA” for GTA Azure Community, “TD” for Toronto .NET.
  • Overflow counts use “+n”, never “…”.
