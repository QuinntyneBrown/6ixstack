Empty state

Empty states say why a region has nothing to show, and give one clear next step.

WCAG 2.2 AAStatus: stableContent pattern

Overview

An empty state fills a region that has nothing to show, and says why and what to do next. 6ixstack has four kinds:

  • First run / nothing yet: the region has never had content ("No notifications yet").
  • Quiet period: nothing in the time range ("No events in the next two weeks").
  • No results: filters or search removed everything ("No events match those filters").
  • Permission or error: the person can't see it or it didn't load ("Only moderators can review submissions", "This event didn't load").

For a whole-page HTTP error (404, 403, 500, offline) use the error page. For a load error above content that is still useful, use an alert. The success panel (a completed form) shares this structure and is documented here.

Anatomy

  1. Icon64px circle in --color-accent-subtle; 24px glyph; decorative.
  2. Title--text-h3; a heading at the region's level.
  3. TextOne or two sentences, max 36ch, --color-fg-muted.
  4. ActionsOne primary, one optional secondary.

Responsive behaviour

  • Centred at every width; text wraps at 36ch.
  • Below 360px the two actions stack, primary first, each full width.
  • In the events page's two-column layout (≥ 1024px) the empty state fills the list column and the map column stays, showing "0 across the GTA".
  • .empty--compact is used inside sections at every width; the full size only in a page's main region.

Theming

The icon circle uses --color-accent-subtle with --color-fg-accent; the error variant swaps to --color-danger-bg and --color-danger-icon; the success panel to --color-success-bg and --color-success-icon. Text is --color-fg-default and --color-fg-muted.

Accessibility

Role and pattern

Plain content: a heading, a paragraph and links or buttons. The heading level continues the page outline (h2 in a page's main list, h3 inside a section, h1 only when it is the whole page, as in event-detail/error). When the empty state appears after filtering, the result line (role="status") announces "0 events", so the empty state itself needs no live region.

Keyboard

KeyAction
TabReaches the primary action, then the secondary.
EnterFollows the link or activates the button.

Focus

Focus is not moved to the empty state. After "Clear filters" focus returns to the filter bar and the list re-renders.

Labelling

The icon is decorative (aria-hidden). Action labels name the object ("Get a feed for Kubernetes").

Contrast

Motion

None. Empty states appear in place without animation.

Touch

Actions are medium buttons (40px) with 12px between them.

Content

  • Title: what is empty, specifically. "No communities in Oakville yet", not "Nothing here".
  • Text: why, and what usually happens next. "Organizers usually post January meetups in the first week of the new year."
  • No-results text suggests the change most likely to help: another topic, include streaming.
  • Permission text says who they are signed in as and who can grant access.
  • Error text says it is not their fault: "nothing you did caused this".
