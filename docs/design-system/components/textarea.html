Textarea

A multi-line input for event descriptions, contact messages and the reason a moderator rejects a submission or an organizer cancels an event.

WCAG 2.2 AAStatus: stableNative <textarea>

Overview

Use a textarea when the answer is a sentence or more. It always sits in a form field with a visible label and usually help text that says how long the answer should be. For one line use a text field.

Anatomy

  1. Label--text-label.
  2. Text areaMin height 2.5 × control height (100px), --text-body.
  3. Resize handleVertical only.
  4. Help or counterBelow, linked with aria-describedby.

Variants

Two or three sentences. Markdown links are fine.
We reply within two working days.95 / 1000
Default with help text; with a character counter.

Sizes

One size: full width of the column. Set rows to the expected length (3 for a reason, 4–5 for a description or message); the minimum is 2.

States

VariantDefaultHoverFocusInvalidDisabledRead-only
Textarea

Both themes

Responsive behaviour

  • Full width of its column at every breakpoint.
  • Resize is vertical only, so the layout never breaks horizontally.
  • On phones the on-screen keyboard can cover it; the page scrolls it into view with scroll-padding.

Theming

Identical to the text field: surface, strong border, orange focus, danger border when invalid.

Accessibility

Role and pattern

Native <textarea> with <label for>; help, counter and error linked through aria-describedby; aria-invalid when invalid.

Keyboard

KeyAction
Tab / Shift+TabMoves into and out of the control.
Typing, ← →, Home EndNative text editing.
EnterInserts a new line (never submits).

Focus

Same as the text field: orange ring at 0 offset plus orange border.

Labelling

Visible label; counters are announced politely only when the limit is near, not on every keystroke.

Contrast

Value text in input
Placeholder
Input border on card
Invalid border
Error text
Focus ring on surface

Motion

Border transition over --duration-fast.

Touch

The whole area is the target; at least 100px tall.

Content

  • Help text sets length and audience: “Shown on the listing and emailed to everyone going.”
  • Errors ask for what is missing: “Tell attendees why, in a sentence or two.”
