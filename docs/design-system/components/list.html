List

Lists stack similar items, each with a title, a meta line and at most one action. Option lists turn each item into a large choice button.

Overview

Use a list when items share a shape but are not compared column by column: calendar feeds to subscribe to, speakers at an event, the calendar apps an event can be added to. Use a table when people compare attributes across rows, and event rows for event listings.

  • Simple list (.list) — rows separated by hairlines, one trailing action.
  • Option list (.option-list + .option-btn) — each row is the action; used in dialogs to pick one destination.
  • People list (.people + .person) — avatar, name and role, wrapping into a grid.

Anatomy

  1. Leading tile (optional)logo tile or avatar; hidden below 640px in list items to give the text room.
  2. Title.list__title, label font.
  3. Meta.list__meta, small muted text; separate facts with “ · ”.
  4. Trailing actionOne small button; its aria-label names the item.

Responsive

  • Below 640px the leading logo tile in .list__item hides so titles keep their width; the action stays on the same row.
  • .people collapses to one column below 30rem and grows to as many 15rem columns as fit.
  • Option buttons are always full width; in a mobile sheet they stack with 8px gaps.

Theming

Lists use surface, border-default and fg-muted tokens. Option buttons read --color-bg-surface, hover to --color-bg-subtle with a --color-border-strong edge. Avatars inside people lists use the accent-subtle pair, which flips in dark theme automatically.

Accessibility

Role and pattern

A plain <ul>; interactive items are real <a href> (navigation, downloads) or <button> (in-page action). No listbox role: an option list is a set of links, not a selection widget.

Keyboard

KeyAction
Tab / Shift+TabMoves between option buttons, people links or row actions.
EnterFollows the link or activates the button.
SpaceActivates a button item; on link items it scrolls, as native links do.

Focus

The shared ring draws around the whole option button or person link.

Labelling

Each option’s accessible name is its title plus hint (“Google Calendar Opens a new tab”), which tells screen-reader users about the new tab. Trailing icons are aria-hidden. Avatars are aria-hidden because the name follows. Row actions carry an aria-label with the item name.

Motion

Option hover changes colour over --duration-fast; the busy spinner keeps turning under reduced motion because it signals progress.

Touch

Option buttons are 52px tall and full width; people links include the avatar and both lines in their target.

Content

  • Titles are short nouns: “Everything”, “In the GTA”, “Google Calendar”.
  • Meta lines give counts and scope: “In-person and hybrid events only · 9 in the next two weeks”.
  • Option hints say what happens next: “Opens a new tab”, “Downloads an .ics file”.
  • People roles read “Title, Company” or “Award · Community”.
