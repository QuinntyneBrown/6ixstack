Link

Links take people somewhere: to an event, an organizer's page, a ticket site. They are always underlined so they never rely on colour.

WCAG 2.2 AAStatus: stableNative <a href>

Overview

Use a link when activating it navigates and changes nothing. If it changes something, it is a button. 6ixstack has three kinds:

  • Inline — inside prose and captions (“No account needed to submit an event”).
  • Arrow link (.arrow-link) — a standalone call to go further: “Get a calendar feed →”, “All events this week →”.
  • Back link (.back-link) — “← All events” at the top of detail pages.
  • External — registration, ticket and livestream links that leave 6ixstack and open a new tab.

Anatomy

  1. TextSays where it goes; makes sense on its own.
  2. Underline1px at rest, 2px on hover, 0.15em offset (0.3em on arrow links).
  3. Trailing iconArrow (go further) or external mark (new tab); aria-hidden.

Links take the font of their context. Arrow and back links use --text-label; the arrow link sets --font-size-md.

Responsive behaviour

  • Links wrap with their text; arrow links keep the arrow attached with no break before it.
  • Inline links in captions keep a 24px line box so they remain a 24px target.
  • Back links sit above the page title at every width.

Theming

Links read --color-fg-link (ink in light, off-white in dark) and turn --color-fg-link-hover (orange 700 in light, orange 300 in dark) on hover. Back links use --color-fg-muted rising to --color-fg-default. On the feature card and event map, links inherit the on-feature and map foregrounds.

Accessibility

Role and pattern

Native <a href>; see the APG Link pattern. Never a <span> with a click handler, and never a link without href.

Keyboard

KeyAction
TabMoves to the link.
EnterFollows the link (Space does not; that is the button contract).

Focus

The shared orange ring on :focus-visible; inline links show it around the text box.

Labelling

The text is the name and must make sense alone: “Register on Luma”, not “here”. External links add visually hidden “(opens in a new tab)” and an external icon. Icons are aria-hidden.

Motion

The arrow slides 4px on hover over --duration-fast; reduced motion zeroes it.

Touch

Standalone links have a 24px minimum line box; links in dense metadata are spaced at least 8px apart.

Content

  • Describe the destination: “View event”, “Register on Luma”, “GTA Azure Community”.
  • Arrow links are short calls to go further, sentence case, no trailing punctuation.
  • Back links name the list they return to: “All events”, “All communities”.
  • Never “click here”, “read more” or a bare URL.
