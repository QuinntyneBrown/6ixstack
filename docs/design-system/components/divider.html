Divider

A divider is a hairline that separates groups of content when spacing alone is not enough.

WCAG 2.2 AAStatus: stableNative <hr>Decorative

Overview

Prefer space over lines: 6ixstack separates sections with the spacing scale (--space-8 to --space-12). Reach for a divider when two groups sit close together and are different in kind, such as the primary and secondary links in the mobile menu, or when a toolbar needs a vertical break between control groups. Card footers, dialog footers and table rows draw their own hairlines; do not add a divider to them.

Anatomy

  1. Rule1px --color-border-default, no other styling.
  2. Spacing--space-6 above and below by default; --space-2 with .divider--tight.

Sizes

One thickness (--border-width-hairline); spacing is the only variable, through .divider--tight.

States

Dividers are decorative and have no interactive states.

Responsive behaviour

  • Horizontal dividers span their container at every width.
  • A vertical divider in a toolbar is hidden when the toolbar wraps (below 640px), because a wrapped group already reads as separate.

Theming

Reads only --color-border-default. Under prefers-contrast: more it becomes --color-border-strong automatically through the token.

Accessibility

Role and pattern

<hr> is a native separator. Use it between groups whose meaning changes; a vertical divider is a <span role="separator" aria-orientation="vertical">. Purely visual hairlines inside components are CSS borders, not separators.

Keyboard

KeyAction
–Not focusable; no keyboard interaction.

Focus

Never receives focus.

Labelling

A labelled divider exposes its text (“or”) to screen readers; unlabelled ones announce as “separator” or are skipped.

Contrast

Motion

None.

Touch

Not a target; never place one where it shrinks the gap between two targets below 8px.

Content

  • Labelled dividers use one lowercase word: “or”.
