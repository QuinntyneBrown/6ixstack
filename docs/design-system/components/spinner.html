Spinner

Spinners say “working” when nothing more specific fits: in a busy button or a small panel.

WCAG 2.2 AAStatus: stablerole=status

Overview

A spinner says "working" when there is nothing more specific to show: inside a busy button, next to a retry link, in a small panel that is fetching. It is the last resort among loading indicators.

  • Inside buttons, use the button's busy state (aria-busy="true"), which draws the spinner for you. See button.
  • For a list, card grid or page, use a skeleton that matches the layout. The events page never shows a full-page spinner.
  • For a long task with a known length, use a progress bar.

Anatomy

  1. ArcTop border in --color-accent; one turn per --duration-spin.
  2. TrackFull ring in --color-border-default.

States

A spinner has one state: spinning. It appears after 300 ms (so fast responses never flash it) and is removed when the work ends.

Responsive behaviour

Spinners do not change with the viewport. A panel spinner stays centred in its panel; it is never fixed to the screen.

Theming

Arc --color-accent, track --color-border-default. On accent fills, .spinner--on-accent switches both to --color-fg-on-accent so the spinner stays visible on primary buttons in both themes.

Accessibility

Role and pattern

The ring itself is aria-hidden. It sits inside a role="status" element with visually hidden text ("Loading events"), so the start is announced politely. In buttons, aria-busy="true" plus the changed label do the job.

Keyboard

KeyAction
—Not focusable.

Focus

Never moves focus. If the spinner replaces a focused control (a Retry link), focus moves to the container and back to the result when loading ends.

Labelling

The hidden text names what is loading: "Loading events", not "Loading".

Contrast

Arc on surface
Arc against track
Arc on page

Motion

Rotates continuously at --duration-spin (800 ms), linear. It is a status indicator, not decoration, so it keeps turning under prefers-reduced-motion; --duration-spin is deliberately not zeroed. Pair it with text so it is understood even if motion is disabled by the browser.

Touch

Not interactive.

Content

  • Visible text, when there is any, says what is happening with an ellipsis: "Checking the stream link…", "Saving…".
  • Hidden text names the thing loading: "Loading notifications".
