Button group

A row of related buttons that act as one control: the Where filter (All · In the GTA · Streaming) and the List / Month view switch.

WCAG 2.2 AAStatus: stablerole="group" + aria-pressed

Overview

Use a button group when two to four options are mutually exclusive and switch what the current page shows without leaving it. 6ixstack has two:

  • Segmented (.segmented) — the format filter on events, calendar and the feed builder, with live counts per option.
  • Toolbar group (.btn-group) — joined small buttons for List / Month view.

When the options are separate pages with their own URLs and headings, use tabs or links with aria-current. When there are more than four, or several can be on at once, use topic chips or checkboxes.

Anatomy

  1. Track--radius-lg, 1px --color-border-default, --space-1 padding; scrolls horizontally if it overflows.
  2. Selected itemInk fill (--color-accent) with aria-pressed="true".
  3. CountMono caption, 80% opacity; part of the name (“All 14”).
  4. Unselected itemMuted text, subtle fill on hover.

Variants

Segmented: single select with counts. Selecting an option filters the list in place.

Responsive behaviour

  • The segmented track has max-width: 100% and scrolls horizontally rather than wrapping; at 360px all three options fit.
  • In the filter row the search field takes the remaining space beside it and wraps above it below 640px.
  • The toolbar group keeps icon and label at every width; it is short enough not to need an icon-only form.

Theming

The segmented control reads --color-bg-surface, --color-border-default, --color-fg-muted, --color-bg-subtle and, for the selected item, --color-accent / --color-fg-on-accent. The toolbar group uses the button tokens and switches the pressed button to --color-accent-subtle with an accent border. In dark, the selected segment becomes off-white with ink text.

Accessibility

Role and pattern

A role="group" with aria-label (“Where”, “View”) around native buttons that carry aria-pressed; this is the APG toggle button pattern. When an option navigates (List vs Month are separate URLs), use links with aria-current="page", not aria-pressed.

Keyboard

KeyAction
TabMoves to each button in turn (every option is a tab stop).
Enter, SpaceSelects the option and filters the list.
Shift+TabMoves back.

Focus

Focus stays on the pressed button after selection; the list updates below and the result line (“9 events in the GTA”) is a polite live region.

Labelling

The group label names the dimension; each button's text plus its count is the name (“In the GTA 9”). Counts are not announced separately.

Motion

Background and colour transition over --duration-fast; nothing moves.

Touch

Segments are 40px tall with at least 2px between; group buttons are 32px and inside a toolbar row.

Content

  • Short nouns or noun phrases in sentence case: “All”, “In the GTA”, “Streaming”; “List”, “Month”.
  • Counts are plain numbers; show “0” rather than hiding the option.
  • Keep the same order everywhere the filter appears (events, calendar, feed builder).
