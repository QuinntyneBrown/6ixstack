Select

A native dropdown for choosing one value from a fixed list: city, time zone, topic filter on the communities directory.

WCAG 2.2 AAStatus: stableNative <select>

Overview

Use a select for one choice from five or more known options. For two to four options that should all be visible, use a radio group or a segmented control. The native element is the default: it gives phones their own picker and needs no script. A custom listbox is only considered when an option needs rich content, and then follows the APG Listbox pattern.

Anatomy

  1. LabelAlways visible in forms.
  2. Selected value--text-body.
  3. ChevronDrawn in currentColor; --space-10 right padding keeps text clear.

Variants

Native; a filter with an “All” option; a required select with a placeholder option.

Small, medium (default), large, using the control heights. Prefer medium; small only in dense toolbars.

Select

Both themes

Responsive behaviour

  • Full width in forms; in the communities filter bar two selects sit side by side and wrap below 640px.
  • Phones open their native wheel or sheet.

Theming

Same tokens as the text field. The chevron uses currentColor, so it follows the text in both themes and in forced colours.

Accessibility

Role and pattern

Native <select> with <label for>. A custom version would follow the APG Listbox pattern.

Keyboard

KeyAction
TabMoves to the select.
↓ / ↑Changes the value (Windows) or opens the list (macOS).
Alt+↓, SpaceOpens the list.
Type a letterJumps to the first matching option.
EscCloses without changing.

Focus

Orange ring plus orange border, as on text fields.

Labelling

Visible label in forms. Filters in the communities bar use visually hidden labels (“Topic”, “City”) and an “All topics” first option that states the current filter.

Contrast

Invalid border
Error text

Motion

Border transition only.

Touch

40px tall; the native picker handles touch.

Content

  • Options in a meaningful order: cities by size with “Online only” last; time zones with Toronto first.
  • Filter selects start with “All …”.
  • Changing a select never submits or navigates on its own (WCAG 3.2.2); filters apply on change only when results update in place.
