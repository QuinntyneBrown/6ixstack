Skip link

The skip link is the first thing a keyboard reaches on every page and jumps straight past the header to the content.

WCAG 2.2 AAStatus: stableWCAG 2.4.1

Overview

The skip link is the first focusable element on every page. It is hidden until it receives keyboard focus, then slides in at the top left and jumps past the site header to #main. Keyboard and switch users skip the brand, four nav links and Submit event on every page they open.

  • Every page has exactly one, before the site header, targeting the page's <main id="main">.
  • Do not add more skip links for in-page sections; use headings and landmarks.

Anatomy

  1. Label"Skip to content".
  2. ContainerRaised surface, --radius-md, --shadow-3, shown 16px from the top-left corner above everything (--z-tooltip).

Responsive

Same at every width: 16px from the top-left corner (--space-4). It overlaps the site header while visible, which is intended; it sits above it on the --z-tooltip layer and disappears again when focus moves on.

Theming

Reads --color-bg-surface-raised, --color-fg-default, --shadow-3 and the shared focus ring. In dark theme the raised surface is lighter than the canvas, so it still reads as on top.

Accessibility

Role and pattern

A plain same-page link, <a href="#main">, satisfying WCAG 2.4.1 Bypass Blocks. The target <main id="main"> receives focus when the link is followed (add tabindex="-1" if a browser does not move focus).

Keyboard

KeyAction
Tab (first press)Reveals and focuses the skip link.
EnterMoves focus to the main content.
Tab againHides it and continues to the brand link.

Focus

It shows the shared focus ring as well as moving into view, so it is obvious where focus is. It is never covered by the sticky header.

Labelling

The link text is the name; no ARIA. Keep the wording identical on every page (WCAG 3.2.4).

Contrast

Label on raised surface
Focus ring on raised surface

Motion

It slides in over --duration-fast; with reduced motion it appears in place.

Touch

Keyboard-only; it does not appear for touch. Its 40px height keeps it usable with switch access.

Content

  • Always "Skip to content". Not "Skip navigation" (people do not always know what is being skipped) and not "Skip to main content" on some pages and "Skip to content" on others.
