Text field

A single-line input for short answers: event title, venue, email, price, a feed URL to copy, a search query.

WCAG 2.2 AAStatus: stableNative <input>

Overview

Use a text field for one line of free text. Pick the right type (email, url, search, date, time) and autocomplete so phones show the right keyboard and browsers can fill it. Use a textarea for more than one sentence and a select for a fixed list such as city or time zone. Always place it inside a form field with a visible label.

6ixstack has no passwords: sign-in sends an email link, so the password variant is not part of the system.

Anatomy

  1. Addon (optional)Prefix or suffix unit (“$”, “https://”), subtle fill, part of the border.
  2. Value--text-body 16px, so iOS does not zoom on focus.
  3. Container40px, 1px --color-border-strong, --radius-md.

Both themes

Responsive behaviour

  • Fields are full width of their column; the form grid is one column below 640px.
  • Value text stays 16px at every width so iOS does not zoom.
  • Copy fields keep the button beside the input; the input shrinks (min-width: 0) and the mono value scrolls inside.
  • The header search collapses to an icon button below 768px and opens a full-width field.

Theming

Inputs read --color-bg-surface, --color-border-strong, --color-fg-default, --color-fg-subtle, --color-focus-ring and --color-danger-solid. In dark the surface is #16181d on a #0e0f12 page, the border lightens to #8a8880 (3:1 or better) and the focus ring turns orange 300.

Accessibility

Role and pattern

Native <input> with a <label for>. Help and error text are linked with aria-describedby; invalid fields set aria-invalid="true". Search uses type="search" in a role="search" form.

Keyboard

KeyAction
Tab / Shift+TabMoves into and out of the control.
Typing, ← →, Home EndNative text editing.
EscIn a search field: clears the query.

Focus

The field draws the orange ring at 0 offset and turns its border orange, so the edge itself is the indicator. After a failed submit, focus goes to the error summary, whose links move focus to each field.

Labelling

Every field has a visible label; placeholders are examples (“name@example.com”), never the label. A search field in a toolbar may use a visually hidden label (“Search events”). Optional fields say “(optional)”; required ones are the default and carry required.

Motion

Border colour transitions over --duration-fast; nothing moves.

Touch

40px controls, 44px in the filter row; labels are part of the hit area because they are real <label> elements.

Content

  • Labels are nouns in sentence case: “Event title”, “Venue name”, “Street address”.
  • Help text says what good looks like: “Include the floor or room so people find you.”
  • Errors say what to do: “Enter a title for the event.”, “End time must be after the 6:30 PM start.”
  • Placeholders show the format only: “https://”, “name@example.com”.
