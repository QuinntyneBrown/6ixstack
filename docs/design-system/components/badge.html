Badge and status

Badges label an item with a short, uppercase tag; status labels say where an event submission is in review. Both pair a dot with words.

Overview

Use a badge for a short property of an item that people should notice while scanning: “Cancelled”, “Waitlist open”, “Live now”. Use a status label for workflow state in tables and cards: an organizer’s submission is Draft, In review, Published, Needs changes, Cancelled or Past. Use a count badge on an icon button for unread notifications. For topics, use topic tags, not badges.

Anatomy

  1. Dot6px (badge) or 8px (status) in currentColor; repeats the meaning visually.
  2. Pill22px tall, --radius-full, tone background, overline type in uppercase.
  3. StatusNo pill: dot + sentence-case label in the tone’s foreground colour.

Sizes

Badges and status labels have one size (22px pill, label font). Count badges shrink to 18px only when pinned to an icon button.

States

Badges are static labels and have no interactive states. When a badge seems to need hover, it is really a chip or a link; see topic chip.

Responsive

  • Badges never wrap (white-space: nowrap); in an event row meta line they wrap as a unit with the other meta items.
  • Day-group headings push their badge to the right edge at every width.

Theming

Each tone reads the status token family (--color-*-bg and --color-*-fg). Dark theme swaps to deep tinted backgrounds with light text. The brand badge uses --color-brand with ink text in both themes.

Accessibility

Role and pattern

Plain text in a span; no role. The dot is a pseudo-element, so it is never announced. Status is never colour alone: every badge has words.

Keyboard

KeyAction
—Badges are not focusable.
TabA count badge’s parent button is focusable; the badge itself is aria-hidden.

Focus

None on the badge; the ring draws on the parent control.

Labelling

Count badges are aria-hidden and the parent button’s aria-label says “Notifications, 3 unread”. When the count changes live, update the label; do not announce the badge.

Motion

None. The “Live now” pulse belongs to the .dot--pulse indicator, not the badge, and stops under reduced motion.

Touch

Not a target.

Content

  • One or two words. Badges read uppercase through CSS; write them in sentence case in the markup (“Waitlist open”) so screen readers do not spell them out.
  • Status labels are actionable for the organizer: “Needs changes”, not “Rejected”.
  • Counts above 99 show “99+”; the label keeps the real number.
