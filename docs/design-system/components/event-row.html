Event row

Event rows are the heart of 6ixstack: time, title, organizer, where it happens, topics, price and how many are going, grouped under a day heading.

WCAG 2.2 AAStatus: stable<article> in a list

Overview

Use event rows wherever events are listed by date: the home list, community and speaker pages, search results. Each row is an <article> inside an .event-list, and rows are grouped by day under a .day-group heading. Use a feature card for the one highlighted event and a table for an organizer’s own submissions.

  • The whole row is clickable through the title link’s stretched hit area; there is exactly one link per row.
  • Streaming events replace the venue with “Livestream” in brand orange and show the source time zone under the Toronto time.
  • Cancelled events stay in the list for a week, struck through, with a danger badge.

Anatomy

  1. TimeMono, tabular, Toronto time; <time>. Streams add the source time below (.event-row__source).
  2. Title linkSemibold 18px; its ::after stretches over the row so the row is the target.
  3. OrganizerCommunity or host, muted.
  4. Where.meta-item with pin icon, or .meta-item--stream with the broadcast icon in brand orange.
  5. Topics and badgestopic tags, then at most one badge.
  6. Price“Free” or “$49”; label font.
  7. GoingPeople icon + count; the count’s label says “142 going”.

Responsive

  • Below 640px the row is one column: time on top (with the stream source inline after it), then title, organizer, meta, and price/going on one line at the bottom.
  • From 640px it becomes three columns: a 4.5rem time column, the body, and an aside with price on top and going at the bottom.
  • The meta line wraps; topic tags never break internally.
  • Rows keep scroll-margin-top: 7rem so jumping to a day from the map does not hide the row under the sticky header.

Theming

Rows are transparent on the canvas and lift to --color-bg-surface on hover, which reads in both themes. Streaming icons use --color-fg-brand (orange-700 light, orange-300 dark).

Accessibility

Role and pattern

Each event is an <article> in a <ul class="event-list">, inside a <section aria-labelledby> per day, so screen-reader users can jump by heading (day) and by article (event). The title is an h3 with the only link. This is the “block link” technique: one real link, extended visually with a pseudo-element.

Keyboard

KeyAction
TabOne stop per row: the title link.
EnterOpens the event page.
Heading navigationScreen-reader H jumps between days; 3 between events.

Focus

The title link’s outline is replaced with a ring around the whole row via .event-row:has(a:focus-visible), matching the hit area.

Labelling

The going count has aria-label="142 going"; icons are hidden. Time uses <time datetime>. Cancelled rows also say “Cancelled” in text (badge), not only through the strikethrough.

Motion

Background fades over --duration-fast; dimmed day groups fade over --duration-base. Both instant under reduced motion; smooth scrolling to a day is turned off too.

Touch

The whole row (at least 88px tall) is the target.

Content

  • Times are Toronto time in “6:00 PM” format; streams add the origin (“9:00 AM PT”).
  • Venue: place name, street, city — “Microsoft Canada, 81 Bay St, Toronto”. Streams say “Livestream”.
  • Price: “Free”, “$49”, or “From $15”. Never “TBD”.
  • Going: digits with separators, no “people”.
  • Day headings: weekday, then the date in muted text: “Tuesday November 3”.
