Date tile

A date tile shows month and day as a compact calendar leaf beside an event title. It is a visual anchor; the full date is always in text nearby.

WCAG 2.2 AAStatus: stableDecorative

Overview

Use a date tile where an event is presented on its own (featured card, event page hero) and the date is the first thing people look for. In lists, use the event row time column under a day heading instead; one tile per row would be noise.

Anatomy

  1. MonthThree-letter month, overline type, uppercase, muted.
  2. DayBold numeral, 24px (30px large), line height 1.
  3. LeafSubtle background, --radius-md, 60px square (72px large).

States

Date tiles are decorative and never interactive; the event title next to them is the link.

Responsive

  • The tile keeps its size at all widths and never shrinks (flex: none); the title beside it wraps.
  • In the event hero on phones the tile stays left of the title; it does not stack above it.

Theming

Reads --color-bg-subtle, --color-fg-muted and --color-fg-default; dark theme lifts the leaf to the subtle dark grey.

Accessibility

Role and pattern

Decorative: aria-hidden="true" on the tile. The date must also be readable as text: the facts panel on the event page spells it out, and the featured card’s footer must include the date, not only the weekday.

Keyboard

KeyAction
—Not focusable.

Focus

None.

Labelling

Because the tile is hidden, put a <time datetime="2026-11-05"> with the full date in the adjacent text (or a visually hidden span) wherever the tile is the only visible date.

Content

  • Month: three letters, English, no period (“Nov”, “Sept” is not used; “Sep”).
  • Day: no leading zero (“5”, not “05”).
  • Multi-day events show the first day; the range goes in text (“Nov 5–6”).
