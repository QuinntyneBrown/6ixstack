Accordion

An accordion stacks questions or sections that open in place, so long reference pages like About and Code of conduct stay scannable.

WCAG 2.2 AAStatus: stableNative <details>Not yet used in the mocks

Overview

Use an accordion for reference content people scan for one answer: an FAQ on the About page, the long sections of the Code of conduct. Do not hide anything a person needs to complete a task (form fields, prices, the event time) inside one; and do not use an accordion for navigation, which belongs in tabs or the settings navigation.

The mocks render About and Code of conduct as open prose; the accordion is the core-set option for when those pages grow.

Anatomy

  1. Container1px --color-border-default, --radius-md, surface background.
  2. Summary--text-label, at least 44px tall; the whole row is the toggle.
  3. Indicator“+” that rotates 45° into “×” when open.
  4. PanelMuted body text, 16px padding, no top padding.

Variants

Multi-open is the default: each <details> is independent. Single-open groups give every <details> the same name attribute so the browser closes the others.

Who can submit an event?

Anyone running a free or paid developer event in the GTA, or a talk Toronto developers can stream. Moderators review each submission within a day.

Why are all times in Toronto time?

So the list sorts correctly. Streaming talks from other cities are converted to Eastern Time for you.

Does 6ixstack sell tickets?

No. Ticket and RSVP buttons link to the organizer's own page on Eventbrite, Meetup or Luma.

Responsive behaviour

  • Full width of its container at every breakpoint, capped by the prose measure (--layout-measure).
  • Summaries wrap onto two lines rather than truncate; the indicator stays top-aligned with the first line.

Theming

Reads --color-bg-surface, --color-border-default, --color-bg-subtle (hover) and --color-fg-subtle (indicator). Dark theme needs no overrides.

Accessibility

Role and pattern

Native <details>/<summary>, which the browser exposes as a disclosure with its expanded state; equivalent to the APG Accordion without any ARIA. Put a heading inside the summary only if the page outline needs it.

Keyboard

KeyAction
TabMoves between summaries (and into an open panel's links).
Enter / SpaceOpens or closes the focused item.

Focus

The ring is inset (negative offset) so it is not clipped by the container's border radius.

Labelling

The summary text is the name; screen readers announce “expanded/collapsed” automatically.

Contrast

Summary text
Summary on hover
Panel text

Motion

Only the indicator rotates (--duration-base); the panel opens instantly. Reduced motion stops the rotation.

Touch

Summaries are 44px tall full-width targets.

Content

  • Summaries are the question people would ask, ending with a question mark.
  • Answer in the first sentence; keep panels under 80 words.
