Stat

Stats put one number and its label front and centre: an organizer’s upcoming events and attendance, or the headline count on the home page.

WCAG 2.2 AAStatus: stableTabular numbers

Overview

Use a stat when one number answers the question the page exists for. The organizer dashboard opens with four; the home hero states how many events are coming. Use a table when numbers need comparing across records.

Anatomy

  1. LabelNoun phrase, label font, muted.
  2. ValueTabular figures, h2 size (24px inside a stats row).
  3. Delta (optional)Arrow + sign + period, success or danger colour.

Sizes

Stats have one size: h2 values standalone, 24px inside a stats row. The hero stat follows body-small text.

States

Stats are read-only. They have a loading state and, for deltas, up/down tones.

Responsive

  • The stats row is two columns below --layout-breakpoint-md and four from 768px.
  • Values never truncate; shorten with thousands separators (“1,204”), not abbreviations, up to 99,999.

Theming

Stat cards read surface, default border and fg tokens; deltas read --color-success-fg and --color-danger-fg, which lighten in dark theme.

Accessibility

Role and pattern

Plain text; the label precedes the value in DOM order so screen readers read “Going 318”. Deltas include a sign and words, not only an arrow and colour.

Keyboard

KeyAction
—Not focusable. If a stat links to detail, wrap the whole stat in one link.

Focus

None, unless linked.

Labelling

Loading stats set aria-busy="true"; the skeleton is aria-hidden. Arrow icons are aria-hidden; the sign (“+42”, “−12”) carries the direction.

Motion

Numbers do not count up; they render final. Skeletons shimmer only without reduced motion.

Touch

Not a target.

Content

  • Labels are short nouns: “Upcoming”, “In review”, “Going”, “Feed subscribers”.
  • Use Canadian number formatting: “1,204”; use an en dash “–” when a number does not exist yet.
  • Deltas name the period: “+42 this week”.
