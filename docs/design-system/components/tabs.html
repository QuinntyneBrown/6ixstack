Tabs

Tabs switch between views of the same thing, such as an event's About, Agenda, Speakers and Location, without leaving the page.

Overview

Tabs switch between views of the same object in place, without leaving the page: the About, Agenda, Speakers and Location of one event, or the Published, In review, Drafts and Past lists on the organizer dashboard. Only one panel shows at a time.

  • Use tabs when people compare or flip between a few views of one thing and the panels are roughly the same weight.
  • Use a segmented button group to filter a single list (the mocks' Upcoming / Past and List / Calendar controls); the list is one panel whose contents change.
  • Use sidebar navigation when the views are separate sections people scroll to or deep-link to.
  • Never use tabs for steps in a sequence; that is a stepper.

Anatomy

  1. Tabbutton role="tab", 44px tall, --text-label, muted until selected.
  2. Selected indicator2px --color-accent bar on the bottom edge plus accent label colour.
  3. Count (optional).badge--count after the label, with an aria-label that says what is counted.
  4. Trackrole="tablist" with a 1px --color-border-default baseline; scrolls sideways when it overflows.

Variants

Underline tabs are the default and sit on surfaces. Pill tabs sit inside cards and toolbars where an underline would collide with the card edge. Either can carry counts.

Sizes

Medium (44px) everywhere a person taps; small (32px, caption type) only inside dense cards where the tabs sit in a row that is itself not the primary navigation.

Both themes

  • Disabled tabs are rare: prefer hiding a tab whose panel would be empty, or showing the panel with an empty state ("No speakers announced yet").
  • Selected is aria-selected="true" and the roving tabindex="0"; every other tab is tabindex="-1".

Responsive

  • Tabs never wrap onto a second row. When they overflow (common below 768px with five or more tabs) the track scrolls horizontally with the scrollbar hidden; the selected tab is scrolled into view on load.
  • Below 768px, consider whether the panels should become stacked sections instead: if people would scroll through all of them anyway (event About, Agenda, Location), drop the tabs and show the sections in order.
  • The track spans the content column; tabs keep their natural width rather than stretching.

Theming

Tabs read --color-fg-muted (resting label), --color-fg-default (hover), --color-fg-accent and --color-accent (selected label and indicator) and --color-border-default (track). In this palette accent is ink, so the selected tab is an ink underline in light theme and a near-white one in dark theme; the orange brand is never used for selection.

[data-theme="partner"] .tab[aria-selected="true"]::after { background: var(--color-fg-brand); }

Accessibility

Role and pattern

APG Tabs with automatic activation: arrows move focus and select at once, because every panel is already in the page. Use manual activation (arrows move, Enter selects) only if a panel loads data.

Keyboard

KeyAction
TabMoves focus into the tablist (to the selected tab), then out to the panel.
← / →Previous / next tab, wrapping at the ends; selects it.
Home / EndFirst / last tab.
Enter / SpaceSelects the focused tab (manual activation only).

Focus

Shared focus ring around the tab. The panel has tabindex="0" when it has no focusable content, so Tab lands on it next.

Labelling

The tablist has an aria-label ("Event detail sections"); each tab is labelled by its text; each panel is aria-labelledby its tab. Count badges carry an aria-label ("3 items").

Motion

The indicator colour fades over --duration-fast; it does not slide. Panels swap without animation.

Touch

Tabs are 44px tall with 12px side padding, and at least 4px apart. Small tabs (32px) are only used where they are not the main way through the page.

Content

  • Labels are one or two nouns: "Agenda", "In review". No verbs, no "View…".
  • Keep labels parallel and short enough that four fit at 360px.
  • Counts are bare numbers; the meaning lives in the label and the badge's aria-label.
