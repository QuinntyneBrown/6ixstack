Table

Tables compare a set of records on the same columns. In 6ixstack they power the organizer dashboard and the moderator review queue.

WCAG 2.2 AAStatus: stableNative <table>

Overview

Use a table when people scan and compare several records by the same attributes: date, status, attendance. The organizer dashboard lists an organizer’s submissions this way. Use an event row list for the public event listing, where each item reads as a story rather than a record, and a list when items have one or two attributes only.

  • Columns carry one kind of value each; numbers right-align with tabular figures.
  • Row actions sit in the last column and name their row for screen readers.
  • Status uses the status dot + label, never colour alone.

Anatomy

  1. Header rowth scope="col" on the sunken surface, label font, muted colour, sticky inside the wrapper.
  2. Sort buttonA real button inside the header; the header carries aria-sort and shows ↑ or ↓.
  3. Primary cellTitle as a link (.list__title), optional meta line (.list__meta) for a reason or hint.
  4. Status cell.status--* dot + label.
  5. Row actionsSmall buttons; revealed on hover and focus, always visible on touch.

Variants

One table look, two densities of content. Keep the default; the variants below change behaviour, not colour.

Responsive

  • Below --layout-breakpoint-md the table keeps its columns and scrolls inside .table-wrap; never shrink text or hide the status column.
  • Row actions are always visible under (hover: none), so touch users can reach Edit and Cancel.
  • Date and action cells use .nowrap so “Thu, Nov 5 · 9:00 AM” never breaks mid-date.
  • For four columns or fewer on a phone-first screen, prefer a list instead of a scrolling table.

Theming

The table reads surface, sunken surface, subtle and default border tokens. In dark theme the header sits on --color-bg-surface-sunken (darker than the body), and row hover lifts to --color-bg-subtle. Re-theme by overriding semantic tokens on a wrapper; the table has no component tokens of its own.

Accessibility

Role and pattern

Native <table> with a <caption> (visually hidden when the page heading already names it), th scope="col" and numeric cells marked .num. Sortable columns follow the APG sortable table example: a button in the header, aria-sort on the th.

Keyboard

KeyAction
Tab / Shift+TabMoves through sort buttons, row links and row actions in reading order.
Enter, SpaceActivates the sort button; repeated activation toggles ascending/descending.
Arrow keysNot used; the table is not a grid widget, so there is nothing to arrow between.

Focus

Focusing any control in a row reveals the row actions (:focus-within); the shared focus ring draws on the control itself.

Labelling

The actions column header is visually hidden text (“Actions”). Each row action appends the event name in a visually hidden span: “Edit Azure Data & AI Day GTA”, so a list of links makes sense alone. Empty numeric cells use an en dash, which screen readers read as “dash”; pair it with “Not published yet” in a tooltip if the column matters.

Motion

Row-action opacity fades over --duration-fast; reduced motion makes it instant.

Touch

Small buttons in rows are 32px tall with 8px between them; on touch screens they are always visible.

Content

  • Column headers are nouns in sentence case: “Event”, “Date”, “Status”, “Going”.
  • Dates read “Thu, Nov 5 · 9:00 AM” in Toronto time; past rows keep their date.
  • Status labels say what the organizer must do or expect: “In review”, “Needs changes”, not “Rejected”.
  • Put the moderator’s reason under the title as .list__meta: “Add the venue address”.

      <th scope="col"><span class="visually-hidden">Actions</span></th>
    </tr></thead>
    <tbody><tr>…<td class="row-actions nowrap">…</td></tr></tbody>
  </table>
</div>
Class / attributeEffect
.table-wrapBorder, radius, surface and horizontal scroll container.
.tableCollapsed borders, cell padding, sticky sunken header.
th[aria-sort] + buttonSortable header with ↑/↓ indicator.
.numRight-aligned tabular numbers.
.row-actionsHidden until row hover/focus; always visible on touch.
.nowrapCell content never wraps (dates, actions).
aria-selected="true" on trSelected row background.
data-state="hover" on trDocumentation only: forces hover.
