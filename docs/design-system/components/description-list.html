Description list

Description lists pair a label with a value. Facts are the icon-led version that summarises an event: when, where, how to watch, price and attendance.

WCAG 2.2 AAStatus: stableNative <dl>

Overview

Use a description list for read-only key–value details: the facts panel on an event page, submission details in the review queue. Use a table when several records share the keys.

  • Facts (.facts + .fact) — icon, bold primary value, muted secondary value; the icon stands in for the label.
  • Key–value (.dl) — explicit term and value in two columns.

Anatomy

  1. Icon20px column, muted, aria-hidden; names the kind of fact.
  2. Primary value.fact__label, label font.
  3. Secondary value.fact__value, may hold one inline link.
  4. PanelSurface, default border, --radius-lg, 24px padding, 16px between facts.

Sizes

One size. Facts panels fill their column; key–value lists size the term column to its longest label.

States

Description lists are read-only and have no interactive states. An inline link inside a value follows the link component’s states; loading uses skeleton text in the value positions.

Responsive

  • Facts stay one column at every width; the aside that holds them moves below the event body below --layout-breakpoint-lg.
  • Key–value lists keep two columns; long values wrap inside the value column. Below 360px consider stacking (term above value) by switching to .facts.

Theming

Facts read surface, default border, fg-default and fg-muted. In dark theme the panel is --color-bg-surface on the darker canvas, so it still reads as a raised block.

Accessibility

Role and pattern

.dl is a native <dl>; screen readers announce term/definition pairs. Facts use divs because the icon is the label; each primary value is self-describing (“318 going”, “Livestream available”). When a value would be ambiguous without its icon, add a visually hidden term (“Price: ”).

Keyboard

KeyAction
TabReaches inline links only (“Directions”).
—No other keys; the list is not interactive.

Focus

Only inline links receive focus and show the shared ring.

Labelling

Icons are aria-hidden. External links such as “Directions” open in the same tab unless the copy says otherwise.

Contrast

Primary value
Secondary value
Link in value

Motion

None.

Touch

Inline links get at least 24px of line height; keep one link per fact.

Content

  • Lead with the value, not the label: “318 going”, not “Attendance: 318”.
  • Dates are spelled out in the facts panel (“Thursday, November 5, 2026”) and include the time zone (“ET”).
  • Prices name what is included: “$49 · includes lunch”.
  • Say what is and is not streamed: “Keynote and main-stage sessions; labs are in person only”.
