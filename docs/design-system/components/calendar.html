Calendar

The month calendar lays a month of events on a seven-column grid, with a toolbar to move between months and a legend for topic colours. The agenda is the one-day version on an event page.

WCAG 2.2 AAStatus: stableAPG Grid

Overview

Use the month grid when people plan around dates (“what’s on the week of the 9th?”). It is one of two views of the same events; the list view (event rows) is the default and is better for reading details. Use the agenda for the timetable inside a single event.

Anatomy

  1. Weekday headerSunday-first, three-letter abbr with the full name as title; sunken surface.
  2. TodayThe day number in an ink circle (.cal__day--today).
  3. Event chip.cal__event: topic dot + truncated title; a link to the event.
  4. Day cellSurface, 1px hairlines between cells (the grid gap shows the border colour), 72px tall (120px from 768px).

Responsive

  • Below 768px event chips collapse to their topic dot; the title stays in the accessible name (visually hidden), and the legend explains the dots.
  • From 768px day cells are 120px tall and chips show truncated titles.
  • The toolbar wraps: month navigation on the first line, the List/Month switch below it on phones.
  • The grid never scrolls sideways; seven minmax(0, 1fr) columns shrink to fit 360px.

Theming

Day cells use --color-bg-surface, outside-month cells --color-bg-surface-sunken, and hairlines show --color-border-default through the 1px grid gap. Today uses the accent pair, so it inverts in dark theme.

Accessibility

Role and pattern

APG Grid (data grid): role="grid" labelled with the month, role="row" per week, role="columnheader" for weekdays and role="gridcell" per day with an aria-label that gives the date, “today” and the event count. Week rows use .cal__week (display: contents) so the 7-column layout survives.

Keyboard

KeyAction
TabEnters the grid on today (or the first day with events); a second Tab leaves it.
Arrow keysMove one day left/right or one week up/down.
Home / EndFirst / last day of the week.
Page Up / Page DownPrevious / next month (same as the toolbar buttons).
EnterMoves focus into the day’s first event chip; Tab walks its chips, Esc returns to the cell.

Focus

Roving tabindex: one cell is focusable at a time. The focused cell gets the shared ring; chips get their own ring.

Labelling

The toolbar heading has aria-live="polite" so “December 2026” is announced after navigation; previous/next buttons name the month they go to (“Previous month, October 2026”). Topic dots are hidden; the chip text names the event.

Motion

Chip hover is a colour change over --duration-fast.

Touch

On phones chips are dot-sized; the whole day cell is the touch target and opens the day in the list view.

Content

  • Month title: “November 2026”. Weekday headers: “Sun”–“Sat” with full names in title.
  • Day labels: “November 4, 2 events”; “November 2, today, no events”.
  • Agenda: “9:30 AM” times; bold the session type (“Keynote:”) and end with the speaker after an em dash.
