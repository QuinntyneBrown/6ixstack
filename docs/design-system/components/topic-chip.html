Topic chip and tag

Every 6ixstack event carries one or more topics, each with its own hue. Chips filter by topic; tags label an event; dots, fills and rings carry the hue into the calendar and the map.

Overview

Topics are the product’s main filter: AI, .NET, Azure, Angular, React and AWS. The hue is a recognition aid, never the only signal: a topic always appears with its name somewhere nearby.

  • Topic chip (.topic-chip) — a toggle button in the calendar filter row; pressed chips fill with ink.
  • Topic tag (.topic-tag) — static label in event rows, cards and the calendar legend.
  • Topic dot (.topic-dot--*) — the 8px hue swatch inside chips, tags and calendar entries.
  • Fill / ring / stroke (.topic-fill--*, .topic-ring--*, .topic-stroke--*) — the same hue for map marks: fill = in person, ring = hybrid, stroke = stream arc.

Anatomy

  1. Topic dot8px circle in the topic hue; 6px inside tags; ringed in the on-accent colour when the chip is pressed.
  2. LabelThe topic name exactly as the product spells it.
  3. Chip container40px tall pill, default border, surface background; ink fill when pressed.
  4. TagNo container: dot + small muted text.

Map and timeline marks

On the ink map the hues switch to their bright versions; fill marks in-person events, ring marks hybrid.

Sizes

Chips have one size (40px, a comfortable target on phones). Tags follow the surrounding small text.

Responsive

  • The chip row wraps (.chip-row, 8px gaps); it never scrolls sideways, so all six topics stay visible at 360px.
  • Tags in event rows wrap with the other meta items.

Theming

Topic hues are semantic tokens (--color-topic-*) over primitives. Dark theme points them at the -bright primitives, and the event map does the same locally because it is ink in both themes. Pressed chips use --color-accent / --color-fg-on-accent, so they invert in dark theme.

Accessibility

Role and pattern

Filter chips are native <button aria-pressed> toggle buttons (APG Button, toggle variant) inside role="group" with aria-label="Topics". Tags are text. Dots are aria-hidden.

Keyboard

KeyAction
Tab / Shift+TabMoves between chips; each chip is a tab stop.
Space, EnterToggles the chip; the list below updates and a live region announces the new count.

Focus

Shared ring around the pill; on a pressed chip the ring’s offset gap keeps it distinct from the ink fill.

Labelling

The visible topic name is the accessible name; screen readers announce “AI, toggle button, not pressed”. Never rely on the hue: the six hues are not distinguishable for everyone.

Content

  • Use the official topic names: “AI”, “.NET”, “Azure”, “Angular”, “React”, “AWS”.
  • An event shows at most three tags; more topics go on the event page.
  • A new topic needs a hue that passes 3:1 on surface in both themes and a bright version for the map before it ships.
