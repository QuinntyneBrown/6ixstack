Breadcrumb

A breadcrumb shows where a page sits and links each level above it; on 6ixstack's shallow pages it is usually a single back link.

Overview

A breadcrumb shows where a page sits in a hierarchy and links each level above it. 6ixstack is shallow: most detail pages are one level below a list, and the mocks use a single back link ("All events", "Your events") instead. The breadcrumb is the core-set component for when a page is two or more levels deep, such as an event reached through a community.

  • Use a back link when the page has exactly one parent (event detail → Events, speaker → Speakers, edit event → Your events).
  • Use a breadcrumb when there are two or more ancestors and people need to jump to any of them.
  • Never use either as the only navigation; the site header is always there.

Anatomy

  1. Ancestor linkMuted, no underline until hover; one per level above the page.
  2. Separator"/" drawn by CSS in --color-fg-subtle, so it is not read aloud.
  3. Current pagePlain text with aria-current="page", medium weight, default ink.

Responsive

  • Below 768px: show only the parent, as a back link with a left arrow ("‹ Toronto .NET Meetup"), so the trail never wraps above the page title.
  • 768px and up: show the full trail; collapse middle levels into the ellipsis menu if it would still wrap.
  • The current page's name may truncate with an ellipsis; ancestor names never do.

Theming

Reads --color-fg-muted (links), --color-fg-default (hover and current), --color-fg-subtle (separator) and --text-body-sm. Nothing is themed separately.

Accessibility

Role and pattern

APG Breadcrumb: <nav aria-label="Breadcrumb"> around an ordered list; the last item has aria-current="page". The collapsed menu follows the menu button pattern.

Keyboard

KeyAction
TabMoves through the ancestor links (the current page is not a link).
EnterFollows the link, or opens the collapsed-levels menu.

Focus

Shared focus ring on links and the ellipsis button.

Labelling

The landmark is labelled "Breadcrumb"; the separators are CSS so they are not announced; the ellipsis button says how many levels it hides ("Show 2 more levels"). A back link names its destination ("All events"), never just "Back".

Contrast

Ancestor link on page
Current page on page
Separator on page

Motion

None; colour changes on hover are instant.

Touch

Links are inline text; give the trail --space-2 gaps so adjacent targets are at least 24px apart, and the back link a 44px row on phones.

Content

  • Use each page's own title, shortened only if it is longer than five words.
  • Start from the top-level section ("Communities"), never from "Home".
  • Back links say where they go: "All events", "Your events", "All speakers".
