Component · Layout

Layout primitives

Container, stack, cluster, grid and page grid are the five layout classes every 6ixstack page is assembled from; they own spacing between things so components don't.

WCAG 2.2 AAStatus: stableCSS onlyReads --layout-* tokens

Overview

Components never set their own outer margins. Layout primitives place them:

  • Container (.container, .page) caps width at 80rem and applies the page margin.
  • Stack (.stack, .stack-gap) puts children in a column with one gap.
  • Cluster (.cluster) wraps inline items such as buttons, tags and meta items.
  • Grid (.grid, .grid--auto, .card-grid) aligns to the 4/8/12-column layout grid or auto-fills cards.
  • Page grid (.page-grid, .page-grid--map) is the two-column page template: content plus sidebar, or event list plus map.

Anatomy

  1. Margin--layout-margin: 16 / 32 / 48px.
  2. Column--layout-columns: 4 / 8 / 12.
  3. Gutter--layout-gutter: 16 / 24 / 32px.

States

Layout primitives have no interactive states.

Responsive behaviour

BreakpointColumnsGutterMarginPage grid
Base (0–767px)416px16pxOne column; map above the list
--layout-breakpoint-md 768px824px32pxOne column
--layout-breakpoint-lg 1024px1232px48pxContent + sidebar; list + map

Primitives contain no media queries of their own except the page grids; the tokens change at the breakpoints and everything follows.

Theming

Layout primitives draw nothing and read no colour tokens, so they are identical in every theme.

Accessibility

Role and pattern

Plain <div>s with no role. Choose the semantic element for the content (<main>, <section>, <ul>) and add the class to it: <ul class="card-grid">.

Keyboard

KeyAction
–Not focusable.

Focus

Visual order must equal DOM order. The one exception, .map-col with order: -1, moves a non-essential visual (the map) above the list on phones; its controls come after the list in tab order, which is acceptable because the list is the primary content.

Labelling

Not applicable; landmarks and headings come from the content.

Contrast

Demo grid labels

Motion

None.

Touch

Gaps between adjacent targets are at least 8px (.cluster uses 12px).

Content

Layout primitives carry no copy of their own.
