# 07 · Approve submission

One paragraph per screenshot, read by Kokoro-82M with the af_heart voice.

## 01-review-queue

Approve submission is how a moderator puts a good event in front of everyone. In the review queue, each
submission has an Approve button right on its card, next to the checks that tell you it's ready.

## 02-approved-with-undo

One click and it's approved. The card leaves the queue, and a message confirms it, with Undo for a few seconds in
case you clicked the wrong one. The organizer hears about it only once that window has passed.

## 03-live-in-the-list

And there it is, live in the events list for everyone to find. Check, approve, and the community sees it.
