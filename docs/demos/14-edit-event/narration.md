One paragraph per screenshot, read by Kokoro-82M with the af_heart voice.

## 01-dashboard-edit

Plans change, and Edit event lets you keep your listing right. Start on your dashboard and choose Edit next to
the event.

## 02-change-start-time

Everything you entered is already filled in, with its status on top: published, three hundred eighteen going.
Here, the day now starts at nine thirty, so change the start time.

## 03-changes-saved

Save, and it's done. Changes go live right away, and everyone going, plus every calendar feed that includes the
event, sees the new details within the hour.

## 04-listing-updated

On the public listing, a clear notice says the start time changed, so nobody turns up early. Calendar apps pick
it up on their own.

## 05-past-event-read-only

Past events stay as a record, so they can't be edited. Want to run it again? Duplicate it as a new event. Keep
your listings accurate, in a couple of clicks.
