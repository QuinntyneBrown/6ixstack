# 22 · Report a problem

One paragraph per screenshot, read by Kokoro-82M with the af_heart voice.

## 01-event-page

Spotted something off about an event? Report a problem lets you tell the moderators. It's at the bottom of every
event page.

## 02-report-a-problem

Choose what's wrong: the date or venue, a cancellation, a broken link, spam, or a code of conduct concern.

## 03-choose-a-reason

Add a few details if you can, and your email if you'd like a reply. The organizer never sees who reported.

## 04-report-sent

Send it, and a moderator checks it the same day. Help keep every listing right.
