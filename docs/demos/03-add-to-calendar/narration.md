# 03 · Add to calendar

One paragraph per screenshot, read by Kokoro-82M with the af_heart voice.

## 01-upcoming-event

Add to calendar lets you put any upcoming event straight into the calendar you already use, no account needed.
Start on the event's page.

## 02-add-to-my-calendar

Choose Add to my calendar. The dialog repeats the event, the day and the time in Toronto, and where it is, so
you know exactly what you're saving.

## 03-google-and-outlook

Pick Google Calendar or Outlook and a new tab opens with everything already filled in. Just press save.

## 04-ics-downloaded

For Apple Calendar or any other app, 6ixstack downloads a calendar file. A message confirms it, and when you
open the file, the time shows up correctly wherever you are.

## 05-file-failed

If the file can't be made for some reason, the dialog tells you plainly, and every option is still there,
including Google and Outlook.

## 06-retry-works

Try again, and the file comes through. That's Add to calendar: one tap from an event to your own calendar.
