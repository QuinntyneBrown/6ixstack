# Support

## Using 6ixstack

| You want to…                     | Do this                                                                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Fix wrong details on an event    | Use **Report a problem** on the event's page.                                                                            |
| Ask a general question           | Use the [contact page](https://6ixstack.dev/contact) or email hello@6ixstack.dev.                                        |
| Report a code of conduct concern | Email conduct@6ixstack.dev.                                                                                              |
| Report a bug in the app          | Open an [issue](https://github.com/QuinntyneBrown/6ixstack/issues) with steps to reproduce and any reference code shown. |
| Request a feature                | Open an [issue](https://github.com/QuinntyneBrown/6ixstack/issues) describing who it helps.                              |
| Report a security issue          | Follow [SECURITY.md](SECURITY.md). Don't open a public issue.                                                            |

## Working on the code

Start with the [README](README.md), then [CONTRIBUTING.md](CONTRIBUTING.md) and [AGENTS.md](AGENTS.md).
Search existing issues before opening a new one.

## Response times

6ixstack is run by volunteers. We read every issue and message, but can't promise a response time.
